Two Popularity sources (RespectASO estimate and Apple Ads) and why you choose

RespectASO knows two popularity sources: its own estimate (EST) and, when you connect Apple Ads, Apple's official search popularity (ASA) from the Apple Ads Platform API - Apple's weekly ranking of each category's 500 most-searched terms. Each cell shows the one value that powers your scores; hover its badge for the full story, including the other source's value. You pick the source in Settings → Popularity Source.

Reading the badges

  • ASA — Apple's official value for this keyword (reported values start around 40 on the 1–100 scale).
  • EST — RespectASO's estimate, calibrated against Apple's official data so both speak the same 1–100 scale.
  • EST* — this keyword is outside Apple's published top terms, so the calibrated estimate covers it, capped just below the least-reported value of its category. Hover the badge for the exact numbers.

Reading the arrows

  • (↑6) — change since this keyword's previous check: popularity moved up 6 vs the last snapshot. The same arrows appear on difficulty and rank.
  • ▲ / ▼ — Apple's weekly movement: the keyword's official popularity rose or fell vs the previous dataset week (hover for the exact change).

Where Apple publishes a value, it is Apple's own measurement; where it doesn't, the estimate steps in - clearly badged, on the same scale, so every keyword stays comparable. How both sources work →
